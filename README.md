# 犬の腎臓サイズ参考計算機

VARSの独立した参考計算アプリです。犬の体重から左右腎臓の長径・短径・横径・体積を予測し、任意のCT実測値との比を表示します。VARS本体から独立して動作します。

**アプリ：0.1.0-rc1／公開準備版（2026-11-21）**

## 基礎研究と使用モデル

原 健人・柿崎竹彦ら（2026）「CT検査を受けたイヌにおける腎臓サイズと体重との関係」『獣医画像診断』第23号、3–11頁。

使用モデルは `renal-ct-20261121-r2-provisional`。原著元データ122検査（暫定121個体、追加症例0件）を原尺度の非線形最小二乗法で再解析した `y = a × BW^b` です。計算には丸め前の係数を使用します。同一犬の別時期検査2件を含みます。一方ずつを除いた感度分析の予測値の最大変化は、1.37〜45 kg・全8項目で0.4862%でした。中心式は122検査モデルを維持しています。[感度分析](docs/SENSITIVITY.md)

## 利用できること

- 体重と左右腎臓を選び、4項目の予測値と曲線を表示する。
- 任意のCT実測値を入力し、実測値／予測値を確認する。左右の入力を別々に保持する。
- 探索的な名目95%個体予測帯を任意で表示する。**初期状態では非表示**。

## 適用上の注意

- **犬のCT計測モデルです。単純X線・超音波への直接適用は未検証です。**
- 正常・異常、腎腫大・腎萎縮、病因を自動判定しません。
- 対象の実体重範囲は1.37〜45 kg。範囲外は外挿として表示します。1.8 kg未満は1検査、30 kg超は11検査です。
- 予測帯は探索的な個体予測の参考表示です。健康犬の正常範囲、95%基準範囲、平均値の95%信頼区間ではありません。平均±2SDの呼び替えでもありません。外部検証は未実施です。
- 左腎体積の係数 `a` の標準誤差は原著記載0.8と再計算0.5166が不一致です。原因は未解決で、原著の値を修正していません。[既知の制限](docs/KNOWN_ISSUES.md)
- 体重と任意の実測値は配信サーバーで計算します。アプリは入力をファイル・DBに保存しません。[入力情報の取り扱い](docs/PRIVACY.md)

## ローカル起動

Python 3.12を使用し、このREADMEがあるフォルダで実行します。

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

Windowsでは仮想環境の有効化に `.venv\Scripts\activate` を使います。

```sh
python -m unittest discover -s tests -v
```

テストは架空の入力値とRで算出した集計予測値のみを使用します。公開パッケージに個体別計測データは含めません。

## Streamlit Community Cloudへの公開

入口は `streamlit_app.py`、Pythonは **3.12**、依存関係は `requirements.txt`。APIキー・Secrets・Rのインストールは不要です。公開方法と最終確認は[公開手順](docs/DEPLOYMENT.md)をご覧ください。

## 配布ファイル

`assets/model.json` は集計係数と来歴、`assets/exploratory_prediction_grid.csv` は共通の生成体重グリッド上の集計曲線、`assets/reference_predictions.csv` はテスト用集計予測値です。患者ごとの観測値、原稿、画像、解析用元表、資格情報は含みません。配布対象とSHA-256は `PUBLIC_MANIFEST.json` に記録します。
