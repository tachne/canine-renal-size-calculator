# 同一犬の反復検査に関する感度分析

2026-11-21。原尺度の累乗回帰 `y = a × BW^b` を、R 4.4.3の `nls` で再計算した。対数変換後の線形回帰に置き換えていない。8項目×3条件の24モデルが収束し、全122検査モデルと以前の感度分析を数値誤差の範囲で再現した。

- 基準：両方の検査を含む122検査。各検査を等しく重み付けする。
- Aを除外：同一犬の一方の検査を除いた121検査。
- Bを除外：同一犬のもう一方の検査を除いた121検査。

A・Bは監査用の区別であり、検査の時間順を表さない。除外は感度分析に限り、原データや採用中心式は変更していない。個体別の識別情報・測定値はこの資料に含めない。

全8項目・両条件の最大値は **0.4861569178061131%**。中心式は122検査モデルのままとする。この感度分析は中心予測値の安定性の確認であり、予測帯の被覆率、健康犬の正常範囲、外部症例への妥当性を証明するものではない。今回、予測帯の追加再推定は行っていない。
