# 入力情報の取り扱い

このアプリの入力は、犬の体重、左右の選択、任意のCT実測値です。患者名、飼い主名、診療番号、画像を収集する入力欄は設けていません。

Streamlitでの表示と計算のため、入力値はブラウザーから配信サーバーに送信されます。ローカル起動時は自身のPC、Community Cloudでの起動時はクラウドのサーバーが処理します。「端末内だけで計算する」アプリではありません。

アプリのコードには、入力値をファイル・データベースに保存する処理、外部AIに送信する処理、利用者間で入力を共有する処理はありません。左右の入力は利用中のセッションのメモリに保持します。再読み込み・接続切断後の保持は保証しません。

Streamlitの使用統計送信は同梱設定で無効化しています。ただし、配信サービス自体の運用ログ、アクセス情報等の取り扱いはホスティング事業者の方針に従います。アプリの保存処理がないことは、プラットフォーム側に一切の記録がないという保証ではありません。

公開リポジトリに含めるデータは回帰係数と集計済み予測曲線・テスト用予測値のみです。研究の個体別元データ、対応表、原稿、画像、個体別の交差検証結果は公開対象に含めません。
