## 実ブラウザーでの確認

ローカルの公開準備版をブラウザーで操作し、以下を確認した。

1. 初期10 kg・左腎・実測値空欄で起動し、予測帯はOFF。
2. 20 kgへ変更して予測表・曲線を更新。
3. 左長径6.2 cmを入力後に右へ切り替えると、右の入力は空欄。
4. 右長径6.4 cmを入力すると、右20 kgの予測6.788 cm、比0.943、実測点を表示。
5. 左へ戻ると6.2 cmを保持。
6. 50 kgで外挿と大型犬の少数例の注意を表示。
7. 予測帯をONにすると探索的表示の注意が出る。グラフは45 kgまで帯を表示し、50 kgまでの中心線は破線。
8. モデル詳細のSE不一致、集計対象数、出典の表示を確認。
9. 再読み込みで初期状態に戻り、帯OFF・実測値空欄。左10 kgの表示は長径5.440 cm、短径2.921 cm、横径2.794 cm、体積30.214 cm³。

## 配布と依存関係

公開ファイルは明示した一覧のみでZIPを作成。SHA-256の一覧を同梱し、ZIPの中身・モデル構造・CSV列・機密情報に該当する既知パターンを検査した。元データ、個体別の解析結果、Excel、原稿、画像、秘密情報、過去のGit履歴は含めていない。

Python 3.12／Linux x86_64用バイナリの依存関係解決を、PyPIに対する `pip --dry-run` で確認した。これはCloud上で実際にインストール・起動した結果ではない。直接依存のバージョンを固定し、間接依存はCloudで解決されるため、実公開時にはビルドログと画面の確認が必要。
